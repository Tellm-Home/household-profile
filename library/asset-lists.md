# Household profile: asset lists

November 2026. Indian-first. Each row is one icon to make. **Also covers** lists the other names a doc might use for the same thing; these become aliases in the asset index, so one icon serves all of them.

**Priority:** P1 make first (most households will hit these), P2 next, P3 when a household needs it.
**Have:** ✓ = your current 3D set already covers it. "check" = something close exists, but confirm it reads as this item.
